## About The Business
Sne's Gourmet Table is a fictional premium catering company based in Johannesburg. The website allows customers to view menus, services, testimonials and contact the business for bookings.

Target Audience: Corporate clients, weddings, private events.

## Part 1 Deliverable
This submission contains **ONLY the HTML5 structure** as per Part 1 brief. No CSS styling or JavaScript functionality has been added yet - this will be implemented in Part 2 and Part 3.

## Website Pages (Sitemap)
1. **Index.html** - Homepage / Landing page
2. **about.html** - About the business and chef
3. **menu.html** - Catering menus and food lists
4. **services.html** - Services offered (corporate, weddings, etc)
5. **testimonials.html** - Customer reviews
6. **contact.html** - Contact form and details

All pages are linked via <nav> for navigation.

## Design & Structure
- **Wireframe Design:** Created in Figma to plan layout and user journey before coding.
- **HTML Structure:** Built using semantic HTML5 tags - <header>, <nav>, <main>, <section>, <footer>, <form> for better accessibility and SEO.
- **Folder Structure:** All HTML files in root folder with README.md

## How to Run the Website
1. Download the ZIP
2. Extract the folder
3. Double-click Index.html to open in any browser (Chrome recommended)
